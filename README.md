# DrawerComponent

A responsive, animated, multi-level navigation drawer built with React, Material-UI (MUI), and Framer Motion. Supports dynamic icons, submenu navigation with a back button, and smooth transitions.


# Features

Responsive: Drawer slides from left on desktop and bottom on mobile.

Multi-level Navigation: Supports submenus with a back button and current level info.

Animated: Smooth animation for menu items using Framer Motion.

Customizable: Easily change width, height, colors, and styles via sx. 

Accessible: Supports role, aria-label


# Future Scope
Keyboard Navigation can also be introduced as a new feature. We can also have search option.

Note: I kept the drawer height consistent even with less items as it is good UX for me, full-height drawer feels more predictable.
It avoids the weird jumping layout, and also on mobile it keeps the thumb at the right place for you to touch, you don't have to change the position of your thumb again and again to navigate.
